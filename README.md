# postica. · landing

Landing de acceso anticipado de postica. Se publica con GitHub Pages desde `main` (raíz).

- Un solo `index.html` con CSS y JS inline. Fuentes (Geist, Geist Mono, Instrument Serif) en `assets/fonts/`; imágenes en `assets/img/`.
- Las altas se envían con FormSubmit (AJAX) al email de Rokas. La primera alta dispara un email de activación que hay que confirmar.
- Marca: ver `docs/BRAND.md` en el repo de la app.
